# MoonWars 🌙

An indie tower defense / real-time strategy / first-person shooter game set on the Moon.

## Game Highlights
* **Base Building:** Deploy habitat bubbles, fabricators, and automated turrets.
* **Resource Gathering:** Mine regolith and gems with buggies and utility drones.
* **Low-Gravity Combat:** FPS gunplay with laser rifles on the lunar surface.
